# Kebijakan Privasi Mampat

**Terakhir diperbarui:** 15 November 2026

**Mampat** ("Aplikasi") dirancang dengan privasi sebagai prinsip utama.

## 1. Pengumpulan Data
Aplikasi **tidak** mengumpulkan, menyimpan, mengirim, atau membagikan informasi pribadi, data penggunaan, maupun metadata apa pun.

## 2. Izin Aplikasi
Aplikasi berjalan dengan **nol** izin yang invasif:
*   **Tanpa Akses Internet:** Aplikasi tidak meminta izin `INTERNET`. Secara teknis mustahil bagi Aplikasi untuk mengirim data ke server jarak jauh.
*   **Tanpa Pemindaian Penyimpanan:** Aplikasi menggunakan Pemilih Foto bawaan sistem Android. Aplikasi hanya dapat mengakses file video yang Anda pilih sendiri untuk dikompres dan tidak dapat membaca file Anda yang lain.

## 3. Layanan Pihak Ketiga
Aplikasi **tidak** memuat SDK pelacak, analitik, atau iklan pihak ketiga (seperti Google Analytics, Firebase, atau AdMob).

## 4. Pemrosesan Lokal
Seluruh proses kompresi video dilakukan secara lokal di perangkat Anda menggunakan kemampuan akselerasi perangkat keras Android. Video Anda tidak pernah meninggalkan perangkat.
